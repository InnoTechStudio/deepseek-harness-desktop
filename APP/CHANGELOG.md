# 更新日志

## 1.0.8（2026-09-24）

深色细节微调。

**修复**
- 深色调下，「客户端设置」里打开的开关旋钮与轨道颜色太接近、看不清，现在深色调会换用深色旋钮，一眼能看清开关状态

## 1.0.7（2026-09-23）

开源与更新渠道迁移。

**新增**
- 客户端与内核更新改走 GitHub Release，国内自动测速选最快镜像
- 反馈问题改为 GitHub Issues（浏览器预填，无需登录客户端）

**修复**
- 修复内核更新后界面空白的兼容问题（内核 0.1.5-RC2 自带 bug，RC3 已修）

**调整**
- 版权信息改为「Copyright © 2026 INNOTECH，本程序依据 MIT License 发布」
- 移除所有 Gitee 依赖，全面迁移到 GitHub
- 清理源码中的个人信息与内部代号

## 1.0.6（2026-09-11）

界面与 Windows 打开文件夹。

**修复**
- Windows 上点「在本地打开」会正常打开文件夹
- 侧边栏打开后可以收回

**调整**
- 恢复会话日志下载
- Windows 右上角按钮不再挡住界面

## 1.0.5（2026-09-11）

修复内核更新后无法继续使用会话的问题。

**修复**
- 更新内核后，历史会话会正常显示，也可以继续新建会话
- 更新内核后不再因插件冲突启动失败、反复要求重新安装内核
- 拖入图片会进入当前会话，不会变成全屏打开图片

**调整**
- 去掉与官方功能重复的社区上传插件，避免互相冲突

## 1.0.4（2026-09-09）

修复重装、界面重叠与复制失效的问题。

**修复**
- 换一个位置重新安装后不再提示找不到 Node.js，缺失的运行环境会自动补装
- Windows 上右上角不再出现和最小化、最大化、关闭重叠的按钮
- Windows 上对话下方的复制按钮恢复可用

**调整**
- 移除会话右上角的「Session 日志」导出按钮

## 1.0.3（2026-09-08）

修复内核更新后界面无法使用的问题。

**修复**
- 更新内核后界面不再显示英文报错或一片空白，可直接继续使用
- 更新内核时按钮会显示实时进度和当前步骤，完成后自动关闭窗口
- 更新完成后自动重启服务，不需要手动重启软件
- 修复更新后重新打开软件被退回到首次安装流程、并提示服务启动失败

## 1.0.2（2026-09-02）

界面细节打磨。

**优化**
- 标题栏「新版本」按钮在 macOS 与 Windows 上尺寸一致，位置更协调

## 1.0.1（2026-08-31）

修复桌面通知、安装进度与插件市场。

**修复**
- 安装内核时进度条不再长时间停在 44% 后突然跳变，改为按真实进度实时推进
- 桌面通知改用系统新接口投递，通知会显示本应用的名称和图标
- 开启桌面通知时若被系统拦下，会给出具体原因，并提供直达系统通知设置的按钮
- 统一应用在系统各处显示的名称，不再出现内部代号
- macOS 开机自启改用登录项服务，不再弹出与本应用无关的后台程序提示
- 修复部分插件因系统未放开原生依赖编译而始终安装失败
- 修复插件安装中断后从插件市场「已安装」里消失、无法再更新或卸载的问题
- 修复升级后安装目录残留旧版程序文件

## 1.0.0（2026-08-28）

首个正式版本。

**新增**
- 自动准备运行环境与内核，首次打开即可使用
- 多镜像自动测速选源，支持断点续传
- 与窗口标题栏融合的界面，跟随系统深浅色
- 托盘常驻，关闭窗口后服务继续运行
- 开机自启、防休眠、桌面通知、关闭时退出四项设置
- 内核与客户端自动检查更新
- 设置内一键提交问题反馈，自动附带系统与运行信息
- 服务意外退出后自动重启
